**`Programa em C# com banco de dados MySQL`**<br>
Criado uma aplicação CRUD para avaliação da faculdade da disciplina de POO(Programação Orientada a Objetos).
<br>
-Aplicação Windows Forms/Desktop, com tela inicial e 2 telas separadas para cada tipo de ação.<br>
-Feito cadastro de Gastos com informações de Valor, Forma de Pagamento, Descrição e Data da Compra. opção de atualizar o cadastro ou excluir.<br>
-Pesquisa por Descrição de gasto, visualizando em um gráfico as informações.
